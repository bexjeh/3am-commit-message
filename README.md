A make.fun bounty entry: one commit message — the funniest thing an AI agent
would write right after breaking production at 3 AM.

`main.py` writes the entry to `entry.txt` in the directory named by
`MAKEFUN_OUTPUT_DIR` (fallback `.`): a single line of UTF-8 text, no trailing
newline, deterministic across runs.
